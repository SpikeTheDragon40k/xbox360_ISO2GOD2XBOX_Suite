ISO2GOD2XBOX Suite

Turn your Xbox 360 ISOs into installed games: convert and upload in one go, from Linux.

.iso→Games on Demand→Xbox 360 over FTP
Get started View on GitHub

What it does

Three small Bash scripts: one converts, one uploads, and an optional menu runs both for you.

💿

Batch conversion

Converts every .iso in a folder to Games on Demand format with iso2god-rs, one after another.

🛡️

Your ISOs stay safe

An ISO is deleted only if the conversion succeeded and output was actually written. Not enough free disk space? The game is skipped. Pressing Ctrl+C never deletes the ISO being converted. Or keep every ISO with -k.

📶

Upload with a live progress bar

Sends each game to your console over FTP, with progress, speed and time left for each game and for the whole batch.

⏯️

Resume where you left off

Upload interrupted? Run it again. Files that are already on the console are skipped.

📋

Friendly menu

An optional text menu to preview, convert, upload, change settings and read logs, with no commands to remember.

🔑

Set it up once

All settings live in one .env file. It's only read, never run, and the FTP password never shows up in the process list.

How it works

New to this? Follow these steps in order. Each one tells you what you need and why.

  1. Get your console ready

    You need a modded Xbox 360 running Aurora or FreeStyle Dash, with its FTP server turned on. FTP is how your PC copies files to the console over your home network.

    Write down the console's IP address (something like 192.168.1.50). The default FTP login on Aurora/FSD is xboxftp / xboxftp.

  2. Install what the scripts need

    You need Linux with Bash 4.3 or newer, plus:

    iso2god-rs, the converter. Get it from its GitHub page and put it on your PATH named iso2god.

    lftp for uploading, and, only if you want the menu, whiptail or dialog:

    # Debian / Ubuntu
sudo apt install lftp whiptail
# Arch
sudo pacman -S lftp libnewt
# Fedora
sudo dnf install lftp newt

  3. Download the scripts and fill in your settings

    git clone https://github.com/SpikeTheDragon40k/xbox360_ISO2GOD2XBOX_Suite.git
cd xbox360_ISO2GOD2XBOX_Suite
cp .env.example .env
chmod 600 .env        # it holds your FTP password
nano .env

    The settings that matter most:

    SettingWhat to put
    ISO_DIRThe folder with your .iso files
    GOD_DIRWhere converted games are saved (and uploaded from)
    KEEP_ISOS1 to keep ISOs after converting, 0 to delete them
    XBOX_HOSTYour console's IP address
    XBOX_REMOTE_PATHContent folder on the console (default /Hdd1/Content/0000000000000000)
    DELETE_AFTER_UPLOAD1 to delete local games after a successful upload

  4. The easy way: use the menu

    ./xbox360-tui.sh

    Pick Convert, Upload, or Convert, then upload. Each one shows you a preview first, so you can check what will happen before anything starts. You can also change settings and open the latest log from the menu.

  5. Or run the scripts yourself

    Add -n to any script for a dry run: it shows what it would do without changing anything.

    ./iso2god-all.sh -n     # preview the conversion
./iso2god-all.sh        # convert ISOs to GOD
./god2xbox.sh -n        # preview the upload
./god2xbox.sh           # upload to the Xbox

    While uploading you'll see something like this:

    [3/12] 4D5307E6  Crackdown 2 (7.0 GB)
  Game  [#################-------------]  58%  4.1 GB / 7.0 GB  10.8 MB/s  ETA 04:35
  Total [######------------------------]  21%  16.4 GB / 78.0 GB  game 3/12  ETA 1:35:02

  6. Make the games show up

    On the console, run a content scan in Aurora or FSD. Your new games will appear in the library.

Behind the scenes: lftp doesn't show usable progress when it's run from a script, so god2xbox.sh checks how far lftp has read into each file using Linux's /proc/<pid>/fdinfo. If that isn't available, it falls back to plain output.

FAQ

Common questions, answered from the project's documentation.

What is "Games on Demand" (GOD) format?

It's the format the Xbox 360 uses for games installed to its drive. Converting an ISO to GOD lets you launch it from Aurora or FreeStyle Dash without a disc. The conversion itself is done by iso2god-rs.

Will it delete my ISOs?

By default, yes, but only after a conversion that succeeded and actually produced output. Set KEEP_ISOS=1 or pass -k to keep them. Pressing Ctrl+C never deletes the ISO being converted. Each run writes a log file to the output folder.

My upload stopped halfway. What now?

Just run ./god2xbox.sh again. Files that are already on the console are skipped, so it carries on from where it stopped.

My games are on a USB drive, not the internal hard drive.

Change XBOX_REMOTE_PATH (or pass -r), for example to a path under /Usb0/. If the folder you set doesn't exist, the script lists the folders at the top of the console's FTP server so you can pick the right one.

I uploaded the games but can't see them.

Run a content scan in Aurora or FSD after uploading.

Does it work on Windows or macOS?

It's written for Linux (Bash 4.3+). The live progress bar relies on Linux's /proc; elsewhere the upload falls back to plain output.

Is my FTP password safe?

Keep it in .env with chmod 600. The password is passed to lftp through an environment variable, so it never appears in the process list. Avoid -p on the command line, because it ends up in your shell history. god2xbox.sh warns you if .env is readable by other users, and .env is git-ignored.

Can I use it for games I don't own?

No. Only use these scripts with games you own.
